## 2 每段自己怎么验

每一行都是你要亲手做一遍的事，数字对不上就是没过。

### S1 能看（当前这段）

| 你要亲手做的 | 通过的样子 | 没过的样子 |
|---|---|---|
| 挡掉兵牌名字只看剪影 | 3 秒内分得出步 / 弓 / 骑三条线 | 三条线长得一样 |
| 打一场完整战斗 | 每个 tick 都能看到人朝对面冲、箭飞出去、挨打闪一下 | 只有血条在掉 |
| 一直打到结算 | 兵牌始终在格子里，没有越飘越偏 | 打十几个 tick 后有人飘到格线外 |
| 中端安卓机连打 3 场 | 稳定 50fps 以上 | 掉到 30fps 以下 |
| 冷启动加载 | 首屏 5 秒内出画面（现在 387KB gzip，加素材后看变化） | 超过 8 秒白屏 |

### S2 能操作

| 你要亲手做的 | 通过的样子 | 没过的样子 |
|---|---|---|
| 点「变阵」一次 | 己方整排后撤一格，对面的集火目标跟着换 | 位置不变或换了不生效 |
| 点「投预备队」一次 | 未上场的 2 张牌补进空位，参与结算 | 补进来但打不出伤害 |
| 点「冲锋号」一次 | 全军本 tick 起伤害提升，持续 N tick 后回落 | 只改显示不改结算 |
| 三个额度都点完再点 | 按钮变灰、冷却条按 tick 走 | 能无限点 |

### S3 能成一局

| 你要亲手做的 | 通过的样子 | 没过的样子 |
|---|---|---|
| 从新局打到第 3 层 | 银币账本 80 → 320 → 190 → 80 对得上 | 花超了或对不上账 |
| 完整打完一局 | 12–14 分钟 | 少于 8 分钟或超过 20 分钟 |
| 全程只用一根拇指 | 选牌、布阵、三次微操都单手完成 | 需要两只手或横屏 |
| 故意打输一场 | 立刻回到新局，银币 / 兵牌清空，名望保留 | 卡在结算页或名望一起清零 |

### S4 有构筑

| 你要亲手做的 | 通过的样子 | 没过的样子 |
|---|---|---|
| 连打 5 局 | 至少出现 2 种明显不同的有效阵容 | 5 局都是「重步×3 + 弓×2 + 骑×1」 |
| 拿到双面旗后打一场 | 战报把 1.8 显示成 2.4 | 数值没变或没提示 |
| 6 个事件各点一遍 | 每个都是三选一，没有白拿选项 | 出现「不花任何代价直接拿」 |

### S5 画面成立

| 你要亲手做的 | 通过的样子 | 没过的样子 |
|---|---|---|
| 打开攻城三波演出 | 45fps 以上；关掉泛光 55fps 以上 | 掉到 30fps 以下 |
| 用纸挡住 UI 只看战场 | 仍能看出谁快死了 | 只能靠 UI 数字判断 |
| 看远景与战场对比 | 远景整层模糊降饱和、战场清晰 | 全屏一样清晰或全屏一起糊 |

### S6 发布

| 你要亲手做的 | 通过的样子 | 没过的样子 |
|---|---|---|
| 手机 4G 冷启动 | 首屏 5 秒内出来 | 超过 8 秒白屏 |
| 看构建产物体积 | 首包 ≤ 5MB | 超过 5MB |
| 开飞行模式再进 | 能进游戏并打完一场 | 直接白屏 |
| 刷新页面 | 存档还在 | 进度丢失 |
| 拉到页面最底部 | 素材署名齐全 | 缺署名 |
