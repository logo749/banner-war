# 开发计划与阶段验收

总量 202 小时 ≈ 17 周（按每周 12 小时折算）。起点 2026-11-10，半程第 8.5 周 2027-01-08，第 17 周收尾 2027-03-08。

## 2 每个阶段自己怎么验

每一行都是你要亲手做一遍的事。数字对不上就是没过，别靠感觉。

### M0 骨架与像素上屏（已完成）

| 你要亲手做的 | 通过的样子 | 没过的样子 |
|---|---|---|
| 手机浏览器打开首页，截图放大看边缘 | 2×/3× 放大后像素边缘锐利，没有灰边 | 边缘发糊、出现半透明过渡像素 |
| 长按一张兵牌拖到第 6 行松手 | 兵牌落格、吸附对齐、页面不滚动不缩放 | 拖的时候页面跟着滚，或落点偏半格 |
| 连续拖 10 秒、快速甩动 | 稳定 60fps，没有卡顿掉帧 | 拖到第 3 张开始卡 |

### M1 战斗内核

| 你要亲手做的 | 通过的样子 | 没过的样子 |
|---|---|---|
| 跑 `npm run verify` | 全绿：1v1 32/26/16 tick，剩 19/30、24/30、8/10；攻城余 50%；同输入三次同结果 | 任何一条数字对不上 |
| 摆 5 张打一场遭遇战 | 15–25 秒内出胜负，剩余兵力落在 14%–50% | 一方被 100% 清盘，或打了 60 秒还没完 |
| 同一阵容连打 3 次 | 三次结果完全相同（含 tick 数） | 有随机漂移 |
| 点变阵 / 投预备队 / 冲锋号各一次 | 三次额度用完后再点灰掉，冷却条按 tick 走 | 能无限点，或额度不消耗 |

### M2 单局闭环

| 你要亲手做的 | 通过的样子 | 没过的样子 |
|---|---|---|
| 从新局打到第 3 层 | 银币账本 80 → 320 → 190 → 80 对得上 | 花超了或对不上账 |
| 完整打完一局 | 12–14 分钟一局 | 少于 8 分钟或超过 20 分钟 |
| 全程只用一根拇指 | 选牌、布阵、三次微操都能单手完成 | 需要两只手或横屏 |
| 故意打输一场 | 立刻回到新局，银币/遗物/兵牌清空，名望保留 | 卡在结算页，或名望一起清零 |

### M3 九档与遗物

| 你要亲手做的 | 通过的样子 | 没过的样子 |
|---|---|---|
| 把兵牌名字挡掉，只看剪影 | 3 秒内分得出步/弓/骑三条线 | 三条线看起来一样 |
| 拿到双面旗后打一场 | 战报日志把 1.8 显示成 2.4 | 数值没变或没提示 |
| 把 6 个事件各点一遍 | 每个都是三选一，没有白拿选项 | 出现「什么都不花直接拿」 |

### M4 表现层四层

| 你要亲手做的 | 通过的样子 | 没过的样子 |
|---|---|---|
| 打开攻城三波演出 | 45fps 以上；关掉泛光 55fps 以上 | 掉到 30fps 以下 |
| 用纸挡住 UI 只看战场 | 仍能看出谁快死了（人数条 + 变暗） | 只能靠 UI 数字判断 |
| 看远景与战场对比 | 远景整层模糊降饱和、战场清晰，有伪移轴感 | 全屏一样清晰，或全屏一起糊 |

### M5 局外与打磨

| 你要亲手做的 | 通过的样子 | 没过的样子 |
|---|---|---|
| 新玩家从打开到第一战 | 90 秒内开打，没有强制教程页 | 超过 2 分钟或必须先看说明 |
| 连打 5 局 | 至少出现 2 种明显不同的有效阵容 | 5 局里 4 局都是「重步×3+弓×2+骑×1」 |

### M6 发布

| 你要亲手做的 | 通过的样子 | 没过的样子 |
|---|---|---|
| 手机 4G 冷启动 | 首屏 5 秒内出来 | 超过 8 秒白屏 |
| 看构建产物体积 | 首包 ≤5MB（当前 386KB gzip） | 超过 5MB |
| 开飞行模式再进 | 能进游戏并打完一场 | 直接白屏 |
| 刷新页面 | 存档还在 | 进度丢失 |
| 拉到页面最底部 | 素材署名齐全 | 缺署名 |
